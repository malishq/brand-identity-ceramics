# Логотип «Обжиг»

Знак — пирометрический конус (конус Зегера), согнувшийся в глазке печи: для гончара это сигнал «температура набрана». Слово «Обжиг» набрано Spectral Light и переведено в кривые: верхний штрих «б» повторяет изгиб конуса.

## Файлы

| Файл | Что это | Где использовать |
|---|---|---|
| `logo.svg` | Основная версия: знак (глазурь + шамот) и слово цветом сажи | Светлые фоны: Шамот, белый |
| `logo-inverse.svg` | Одноцветная светлая версия (Шамот) | Тёмные фоны: Глазурь, Сажа, фото |
| `logo-mono.svg` | Одноцветная тёмная версия (Сажа), конус вырезан | Печать в одну краску, гравировка, штамп, факс-варианты |
| `logo-mark.svg` | Знак отдельно, цветной | Аватары, фавикон, клеймо на донышке, стикеры |
| `logo-mark-mono.svg` | Знак отдельно, одноцветный с вырезом | Тиснение, штамп |
| `logo-on-light.png`, `logo-on-dark.png` | Растровые экспорты 1600×700 | Презентации, документы |
| `logo-mark-on-light.png`, `logo-mark-on-dark.png` | Знак 800×800 | Аватары |

Все SVG — чистые кривые без растров и шрифтов, цвет задан явно. Чтобы перекрасить одноцветные версии, замените `fill` в файле.

## Охранное поле

Минимальное свободное поле вокруг логотипа — половина диаметра знака (½ D) со всех сторон. Для знака отдельно — четверть диаметра (¼ D). В это поле не заходят текст, другие знаки и край формата.

```
        ½D
   ┌───────────────┐
½D │ ◖ Обжиг        │ ½D
   └───────────────┘
        ½D
```

## Минимальный размер

| Версия | Экран | Печать |
|---|---|---|
| Логотип (знак + слово) | 120 px по ширине | 24 мм по ширине |
| Знак отдельно | 16 px (фавикон), комфортно от 24 px | 6 мм |

Ниже этих размеров конус внутри знака теряется: используйте только слово или только круг знака.

## Нельзя

- Менять пропорции, наклонять, растягивать.
- Ставить цветную версию на тёмные и пёстрые фоны — для них `logo-inverse.svg`.
- Перекрашивать знак в Накал: накал на макете всегда одна точка, а не логотип.
- Добавлять тени, обводки, градиенты.
- Набирать слово «Обжиг» другим шрифтом или с другим трекингом вместо кривых.

## Как собран

`scripts/make_logo.py` строит конус параметрически (осевая кривая Безье + линейное сужение), переводит глифы Spectral Light в кривые через fontTools и собирает все SVG. Запуск: `~/Desktop/Учёба/.venv/bin/python scripts/make_logo.py`.
